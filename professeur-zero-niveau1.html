🔒 Le casier du Professeur Zéro

⭐ 0

Au collège, tout le monde connaît le Professeur Zéro. Il n'a jamais mis un 5/5 de sa vie !

La principale avait préparé des cartes cadeaux 5/5 pour récompenser les élèves. Mais le Professeur Zéro les a toutes enfermées dans son casier, avec un cadenas à code.

Il oublie tout, alors il a noté son code sur une carte perforée. « Personne ne sait lire le binaire dans ce collège ! », ricane-t-il. Le concierge a retrouvé cette carte dans la photocopieuse…

Le Professeur Zéro est furieux : des élèves ont déjà ouvert son casier en décodant sa carte perforée ! Il a remis les cartes cadeaux 5/5 sous cadenas.

Cette fois, il se croit malin. Sa nouvelle carte contient des caractères (le code ASCII), et il a écrit son code… d'une façon spéciale.

Le concierge a retrouvé la carte dans la photocopieuse, et un post-it collé dessus. Saurez-vous déjouer le piège ?

Ta mission

  1. Apprendre à lire les trous de la carte.
  2. Comprendre la différence entre un nombre et un caractère.
  3. Décoder la carte et trouver le code du cadenas.
  4. Ouvrir le vrai casier et libérer les cartes 5/5 !
💡 À chaque étape, tu peux demander de l'aide. Tu gagnes une ⭐ pour chaque défi réussi sans aide.

Les trous deviennent des nombres

Une ligne de la carte a 8 places. Chaque place a une valeur (en bleu). On additionne les valeurs des trous ; les places sans trou ne comptent pas.

Bonne nouvelle : pour écrire un chiffre de 0 à 9, seules les 4 places de droite (8, 4, 2 et 1) servent !

🧪 Essaie ! Clique sur les ronds pour percer des trous. La calculette fait l'addition pour toi.

Nombres et caractères : attention au piège !

Avec le code ASCII, chaque caractère a un numéro : A = 65, B = 66… Les chiffres aussi sont des caractères, avec leur propre numéro.

⚠️ Le caractère « 4 » n'a pas le numéro 4 : son numéro est 52 ! Les chiffres commencent à 48 : « 0 » = 48, « 1 » = 49…

Espace enseignant

Saisissez le code enseignant.

1 · Le code du cadenas

Réglez votre vrai cadenas à code (3 ou 4 chiffres) sur le même code que la page. Vous pouvez aussi changer le code de la page pour qu'il corresponde à votre cadenas.

🔑 Mot de passe du casier virtuel : eluard. Ne le donnez qu'aux groupes qui n'ont pas accès au vrai casier : l'objectif est d'ouvrir le vrai cadenas en priorité.

2 · Imprimer

La carte perforée du Professeur Zéro (contient le code)

Imprimez à 100 % sur bristol blanc mat, puis perforez les cercles marqués d'une croix (6 mm pour les données, 4 mm pour l'horloge). Une carte par groupe.

Les cartes cadeaux 5/5 (à mettre dans le casier)

Format carte bancaire (85 × 55 mm). Laser : rouge = découpe, noir = gravure, bleu = marquage léger. Les textes sont déjà vectorisés. Planche de 280 × 250 mm.

3 · Déroulé et solution

Niveau Apprenti (élèves en difficulté, 30 à 40 min) : chaque ligne de la carte code un chiffre (0 à 9) avec les poids 8, 4, 2, 1. Aides en 3 niveaux, lecture à voix haute.

Niveau Expert (45 à 55 min) : la carte contient « CODE » puis les chiffres en caractères ASCII (« 4 » = 52), écrits à l'envers (voir le post-it). Les élèves décodent 7 ou 8 octets, distinguent nombre et caractère, puis remettent le code à l'endroit. Les aides sont plus courtes.

Code enseignant : PROFZERO. Les étoiles ne sont pas enregistrées : recharger la page remet tout à zéro. Le bouton ci-dessous débloque toutes les étapes, pour une démonstration.
