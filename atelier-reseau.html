Comment utiliser l'atelier

1

Choisis ton niveau (5ème, 4ème ou 3ème) avec les onglets du haut. Chaque niveau a ses étapes et son quiz de 20 questions.

2

Suis le panneau de gauche : il te donne l'objectif, les instructions pas à pas et une liste de vérifications qui se coche toute seule quand c'est réussi.

3

Pour poser un élément, clique sur sa pastille (PC, Serveur…) puis clique dans le plan. Fais-le glisser pour le déplacer. Clique sur la pastille pour arrêter d'en poser.

4

Choisis l'outil Câble RJ45 dans la barre « Éléments », puis clique sur deux éléments pour les relier. Pour un routeur, clique sur le port 1 ou 2 (petits ronds). Clique sur un câble pour le débrancher.

5

Clique sur un élément pour le renommer et (en 4ème et 3ème) régler ses adresses dans le panneau de droite.

6

Utilise Tester une connexion : clique sur deux appareils. Vert ✅ = ça communique, sinon le message t'explique pourquoi.

7

Les boutons ? ouvrent une définition. Les étapes ⭐ mode expert sont des défis : tu as l'objectif et les vérifications, avec un coup de pouce si besoin.
